## 古い資料とコードの整理

2026-10-24、古い仕様書類に見られた矛盾や不正確な実装状況を解消するため、それらを現行ツリーから削除し、新しい設計資料に置き換えました。

同日、**GitHubにあった以前のGo/C試作コード、旧テスト、サンプル、ベンチマーク、実装用の設定も削除**しました。現在のGitHubブランチにはコンパイラ実装はまだありません。

- **新設計の合意 ≠ 実装済み。**
- 過去の議事録は、当時の設計検討の記録として保持。古いファイルや旧実装を示す記述は、現在の実装状況を意味しません。
- **Gitの履歴は書き換えていません。** 旧資料と旧ソースは削除前のコミットを参照できます。
- **Codebergには変更を加えていません。**
- README、設計資料、議事録、ライセンス、NOTICEは保持しました。

## 資料を更新するときの原則

設計上の合意、検討中の構文、テストで確認した機能を混ぜない。何も決まっていない点を、他の言語の慣習や過去のSimilarityの構文から勝手に補完しない。
